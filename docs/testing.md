# Testing

## Run
`npm install`, then `npm test` (Vitest 5 + jsdom), `npx playwright install` once (on WSL or a fresh Linux machine also `sudo npx playwright install-deps` once, otherwise Chromium can't start and *every* e2e test fails with `error while loading shared libraries`), then `npm run test:e2e` (Playwright; `openApp` in `tests/e2e/helpers.js` starts with both Fit boxes off for predictable geometry, `defaults: true` gives the real defaults; Chromium + a Pixel 5 profile for `touch.spec.js`; `ALL_BROWSERS=1` adds Firefox and WebKit; the two scrollbar-width checks run in Chromium only, since Playwright's headless Firefox and WebKit always draw overlay scrollbars of width 0; clipboard: Chromium gets permissions, Firefox prefs in `playwright.config.js`, WebKit is read by pasting into a text area, `allowClipboard`/`readClipboard` in `helpers.js`), `npm run lint`. CI: `.github/workflows/tests.yml` (lint + fast tests + Chromium on every push, all browsers nightly).

## Layout
- `tests/unit/` pure logic through the page's own functions (time, colours, visibility rules, validation, encryption, translations).
- `tests/app/` behaviour of the screens in jsdom: grid, events, repetitions, choosers, schedules/people, phases, workspaces, import/transfer, share, print/agenda, touch, UI.
- `tests/security/` CSP, escaping with hostile data on every screen, no risky APIs, no network, limits.
- `tests/e2e/` real browser: geometry (sticky, scrollbars, lips flush, zoom, fit), real mouse/keyboard interaction, phone touch, downloads/links/clipboard in two browser profiles, print to PDF, CSP enforcement, performance budgets, accessibility ratchet. `tests/e2e/serve.js` serves `index.html` on http://localhost:4173 (a secure context).
- `tests/helpers/app.js` jsdom harness (the page with `app.css` and each `js/` file inlined in `index.html`'s order; `rawHtml` is `index.html` as served, `scriptFiles` the scripts' list): `openApp`, `setData`, `dragFrom`, `createDrag`, `fillDialog`, fake column geometry (`.day` n spans x 100n..100n+100, top 0), stubbed dialogs/crypto/downloads/clipboard/print.
- `tests/fixtures/` frozen sample files of every published data format (`v<N>/`), the sample household (`household.js`) and the generator (`make.mjs`), see R-DATA-08; read by `tests/app/compat.test.js`.
- `tests/manual/touch.md`: the checklist for real phones (Android Chrome, iOS Safari), 34 steps with the expected result, for what the touch emulation can't prove. The app is on GitHub Pages at https://lvisintini.github.io/week-scheduler/ (serves `main`).
- `tests/requirements.test.js` traceability + description quality.

## Rules
- Every test group is named `R-AREA-nn <what is checked>` after a requirement in `docs/requirements/`; individual test names must say what is expected (≥ 25 characters, no duplicates, no skip/only/todo). The console output is the documentation. New requirement → new ID in its requirement file → tests.
- jsdom has no pointer-event handler attributes (`el.onpointerdown = f` is just a property), so jsdom tests call the handlers directly (`el.onpointerdown(fakeEvent)`, `col.onpointermove(...)`); document-level listeners do receive dispatched events. jsdom has no layout, so anything about sticky/scroll/real drag/print belongs in `tests/e2e`.
- Playwright's `page.evaluate` is exempt from the page's CSP (eval works there); to test `eval` blocking, inject an inline script that runs later (see `security.spec.js`). Headless Chromium never shows the real `beforeunload` dialog, so those tests fire the event and check `defaultPrevented`. Playwright hides scrollbars by default; the config keeps real ones (`ignoreDefaultArgs`).
- Mouse targets in e2e must be on screen: Chromium delivers a move to a negative coordinate, Firefox does not (a target in the hidden early hours is above the visible grid).
- Touch in e2e: `Input.dispatchTouchEvent` with many small moves (`touch`/`swipe` helpers); `synthesizeScrollGesture` does not scroll here.
- Always test dialog flows by clicking real buttons (see the dialog-chaining gotcha in `CLAUDE.md` and `architecture.md`).

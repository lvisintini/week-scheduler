# Product

Static files served as they are by GitHub Pages: `index.html`, `app.css` and classic scripts in `js/` (vanilla JS, no libraries, no build, no network requests). **[U]** Opening it from disk is no longer a requirement: GitHub Pages is how it is shared (locally, `npm run serve`). This made the strict script policy of R-SEC-01 possible. A weekly planner (a workspace may repeat over a cycle of 2–4 weeks, still without dates) organised in **workspaces** (several independent named data sets in one browser), each with overlayable **schedules**, **events** with repetitions, **people**, and background **rhythms** made of **phases** (named parts of the day). English/Spanish UI. **[U]** It serves households and workplaces alike, and its descriptions, tooltips and help say so (R-I18N-02). Repo files: `index.html`, `app.css`, `js/`, `README.md`, `CLAUDE.md`, `docs/` (the specification, code map, testing notes, parked items, known issues), `tests/` and the dev tooling (`package.json`, `playwright.config.js`, `.github/workflows/`).
- **[U]** **Phones are for checking a schedule, not for building one:** a complex week with people is too much to edit on a small screen, and nobody is expected to. On a phone the app is made pleasant to *look at* (and Live View, R-GRID-12, is the main use); editing stays possible but is not designed for.
